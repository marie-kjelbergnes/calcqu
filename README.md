# Calcqu
A website dedicated to make my latex calculations easier on the fly.

## Main goals
- Be able to type in math, and get it converted to latex (be able to copy it back as latex text, and view it rendered as you're typing)
- Be able to solve for variables
- Be able to evaluate expressions
- Be able to simplify things
- Be able to expand
- Be able to evaluate an expression where variables have been replaced with values
- Be able to infer actions 

This project is mainly written in Svelte, and is deployed through Cloudflare Pages.
